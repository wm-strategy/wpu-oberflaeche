# wpu-oberflaeche

Bedienoberfläche des Wertpapieruniversums. Dieses Repo enthält nur die Seite, keine Daten.
Die Seite lädt die Daten mit einem persönlichen GitHub-Schlüssel aus einem privaten Repo; der Schlüssel
bleibt im Browser des Nutzers. Quelle der Seite: `tools/seite_bauen.py` im privaten Repo.
